# Easy Loan
Ứng dụng đăng ký khoản vay bằng Python + Tkinter + SQLite + Random Forest.

Cài:
python -m pip install -r requirements.txt

Chạy:
python main.py

Chức năng: hồ sơ vay, dự đoán, xác suất, tính trả góp minh họa, lưu lịch sử SQLite, đánh giá Accuracy/Precision/Recall/F1.

Dataset là dữ liệu tổng hợp cho mục đích học tập, không dùng để quyết định cho vay thực tế.
